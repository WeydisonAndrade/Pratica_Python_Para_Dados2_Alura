# Pratica_Python_Para_Dados2_Alura
---
Exercícios de Lógica com Python 🐍
Este repositório contém uma coleção de scripts Python desenvolvidos para resolver problemas de lógica de programação, cálculos matemáticos e processamento de dados simples.
---
🚀 Tecnologias Utilizadas
Linguagem: Python 3.x

Paradigma: Programação Estrutural
---
📋 Descrição dos Programas
1. Gerador de Tabuada
O script solicita um número inteiro ao usuário e gera a tabuada correspondente de 1 a 10.

Entrada: Número inteiro (ex: 2).

Saída: Formatação padrão n x i = resultado.
---
2. Verificador de Números Primos
Um programa voltado para conceitos de criptografia e segurança que identifica se um número inserido é primo.

Lógica: Verifica se o número é divisível apenas por 1 e por ele mesmo.

Utilidade: Base para estudos de Ciência de Dados e Segurança da Informação.
---
3. Distribuição de Idades (Previdência)
Analisa a distribuição demográfica de pensionistas em quatro intervalos distintos. O programa lê idades continuamente até que um número negativo seja inserido.

Intervalos monitorados:

[0-25]

[26-50]

[51-75]

[76-100]
---
4. Sistema de Apuração de Votos
Simula a contagem de votos de uma eleição interna com 20 colaboradores e quatro candidatos.

Opções de Voto:

1, 2, 3, 4: Candidatos específicos.

5: Voto Nulo.

6: Voto em Branco.

Saída de Dados:

Total de votos por candidato.

Total de nulos e brancos.

Percentual de votos nulos e brancos sobre o total geral.

Estes programas são parte do treinamento prático da trilha de Especialista em IA da Alura
